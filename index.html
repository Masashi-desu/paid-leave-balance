Static Web App

年次有給休暇 残数計算

日本の一般的な付与ルールをもとに、法定付与・繰越・失効・会社独自付与を整理して、基準日時点の残有給日数を見積もります。

このツールで分かること

  • 法定付与日数と次回付与予定日
  • 現在サイクル開始時点の繰越
  • 消化反映の割当結果と失効内訳
  • 会社独自付与を含めた現在残数

Input

入力

このアプリの「付与サイクル」は、法定付与日から次回付与日の前日までの1年間です。消化日数は 0.5 日刻みで入力します。

Guide

計算前提

モードA

現在サイクルと直前 2 サイクルの消化入力をもとに、古い付与から順に割り当てます。最古サイクルより前の詳細履歴は再現せず、必要最小限の繰越だけ推定します。

モードB

詳細履歴の代わりに「前年度からの繰越日数」を直接使う簡易モードです。過去の失効や消化履歴は再現せず、今年度の残数整理に用途を絞っています。

失効ルール

法定付与分は付与日から 2 年後に失効する前提です。半休は 0.5 日として計算し、会社独自付与は基準日時点で有効な追加分として別加算します。

Result

計算結果

要約に加えて、付与・消化・失効の根拠を表形式で確認できます。

算出根拠の概要

    付与履歴一覧

    法定付与イベントの一覧と、今回の計算でどこまで追跡したかを表示します。

    消化反映一覧

    各サイクルの入力値を、古い付与からどのように割り当てたかを表示します。

    失効内訳一覧

    基準日時点までに失効した未消化分のみを表示します。
